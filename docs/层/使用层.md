# 使用层

使用层是浏览器里的买家端与管理端。代码都在 `crossborder-mall-frontend`。这一层负责展示和收集操作，不连接 MySQL / Redis / RabbitMQ，也不决定库存能不能扣。

总览在仓库根目录 [架构说明.md](../../架构说明.md)。安装与启动命令在 [README.md](../../README.md)。

## 两个壳

| 壳 | 布局文件 | 谁 | 说明 |
|----|----------|----|------|
| 买家 | `src/layouts/UserLayout.vue` | 买家 | 顶栏、分类导航、页脚；子路由挂在 `/` |
| 管理 | `src/layouts/AdminLayout.vue` | 管理员 | 左侧菜单 + 顶栏；子路由挂在 `/admin` |
| 登录 | `src/views/Login.vue` | 未登录用户 | 独立页，不套买家壳 |

路由是 History 模式（`createWebHistory`）。开发时页面在 Vite 上：`http://localhost:3000`。

## 买家页做什么

| 路由 | 页面 | 作用 |
|------|------|------|
| `/` | `Home.vue` | 首页、分类、秒杀入口、热门商品 |
| `/products` | `ProductList.vue` | 分类筛选、分页列表 |
| `/products/:id` | `ProductDetail.vue` | 详情、选 SKU、加购 |
| `/seckills` | `SeckillList.vue` | 秒杀活动列表 |
| `/seckills/:id` | `SeckillDetail.vue` | 抢购、倒计时、轮询结果（需登录） |
| `/cart` | `Cart.vue` | 购物车勾选与改数量 |
| `/checkout` | `Checkout.vue` | 选地址、提交订单 |
| `/payment/:orderNo` | `Payment.vue` | 选择渠道并调用模拟支付 |
| `/orders`、`/orders/:orderNo` | `Orders.vue`、`OrderDetail.vue` | 订单列表与详情、取消 / 确认收货 |
| `/addresses`、`/profile`、`/me` | 对应页面 | 地址、资料、个人中心入口 |

需要登录的路由带 `meta.requiresAuth`。未登录会跳到 `/login?redirect=...`。

## 管理端做什么

路由根带 `meta.requiresAdmin`。进入前会 `auth.fetchMe()`，角色不是 `ADMIN` 则退回首页。

| 路由 | 页面 | 作用 |
|------|------|------|
| `/admin` | `AdminDashboard.vue` | 看板入口 |
| `/admin/products` | `AdminProducts.vue` | 商品 / SKU 维护、上下架 |
| `/admin/categories` | `AdminCategories.vue` | 分类 |
| `/admin/orders` | `AdminOrders.vue` | 发货、取消 |
| `/admin/seckill` | `AdminSeckill.vue` | 活动、上线、**预热库存** |

## 状态与请求怎么离开浏览器

| 模块 | 路径 | 作用 |
|------|------|------|
| Pinia | `store/auth.js`、`cart.js`、`app.js` | Token / 用户、购物车数量、侧栏折叠 |
| 本地存储 | `utils/storage.js` | 持久化 token、用户摘要 |
| HTTP | `api/request.js` + `api/*.js` | `Authorization: Bearer ...`；统一处理业务码 |

`vite.config.js` 把 `/api` 代理到本机后端（当前为 `http://localhost:8088`，与 `application-dev.yml` 一致；Docker / 默认配置多为 `8081`）。

前端 API 前缀写 `/api/v1/...`，与后端 `controller` 上的 `/api/v1` 对齐。

## 视觉约定

样式令牌在 `src/assets/styles/variables.scss`：浅灰页底 `#f4f4f4`、白卡片、圆角、系统中文字体、主色 `#2c3e50`。买家可见文案避免技术黑话（Lua / MQ 等只出现在文档与管理提示）。

## 这一层不做什么

- 不直连数据库、Redis、RabbitMQ  
- 不做最终鉴权（以后端 JWT / `ROLE_ADMIN` 为准）  
- 不实现真实支付跳转
