# 接入层

接入层是 Spring MVC 的 `controller` 包。只负责收 HTTP、校验入参形态、调 service、返回统一 `Result{code,message,data}`。库存怎么扣、Lua 怎么跑，不写在这一层。

包路径：`com.crossborder.mall.controller`。全局异常在 `exception.GlobalExceptionHandler`。

## 统一约定

| 项 | 约定 |
|----|------|
| 前缀 | `/api/v1` |
| 管理前缀 | `/api/v1/admin/**`（需 `ROLE_ADMIN`） |
| 响应 | `com.crossborder.mall.common.Result` |
| 文档 | SpringDoc → `/swagger-ui.html` |

## 买家相关控制器

| 类 | 前缀 | 主要接口 |
|----|------|----------|
| `AuthController` | `/api/v1/auth` | `POST /code`、`/login`；`GET /me`；`POST /logout` |
| `UserController` | `/api/v1/users` | 资料读写 |
| `CategoryController` | `/api/v1/categories` | 列表、树 |
| `ProductController` | `/api/v1/products` | 分页、搜索、详情 |
| `CartController` | `/api/v1/cart` | 列表、加购、改数量 / 勾选、删除、summary |
| `AddressController` | `/api/v1/addresses` | CRUD、设默认 |
| `MallOrderController` | `/api/v1/orders` | 下单、列表、详情、取消、确认收货 |
| `PaymentController` | `/api/v1/payments` | `POST /mock`、按支付单号查询 |
| `SeckillActivityController` | `/api/v1/seckill-activities` | 列表、详情、下单、轮询 `/{id}/result` |
| `UploadController` | `/api/v1/upload` | 商品图上传（管理也会用） |
| `HealthController` | `/api/v1/health` | 健康检查 |

## 管理相关控制器

| 类 | 前缀 | 主要接口 |
|----|------|----------|
| `AdminDashboardController` | `/api/v1/admin/dashboard` | 看板汇总 |
| `AdminProductController` | `/api/v1/admin/products` | 商品 CRUD、上下架、SKU 批量维护 |
| `AdminCategoryController` | `/api/v1/admin/categories` | 分类 |
| `AdminOrderController` | `/api/v1/admin/orders` | 列表、详情、发货、取消 |
| `AdminSeckillController` | `/api/v1/admin/seckill` | 活动、改状态、**预热** `POST /{id}/preheat` |

## 这一层不做什么

- 不写事务边界与 CAS SQL  
- 不直接操作 Redis / MQ（除极少数只读探测外，一律走 service）  
- 不渲染页面
