# 数据层

数据层包括 MyBatis-Plus 实体、Mapper，以及 `src/main/resources/db/` 下的建表与种子脚本。库名：`crossborder_mall`。

## 表与职责

| 表 | 实体 | 说明 |
|----|------|------|
| `tb_user` | `User` | 手机号登录；自动注册；管理员由配置手机号决定，不靠表内角色字段硬编码业务 |
| `cb_category` | `CbCategory` | 分类 |
| `cb_product` | `CbProduct` | SPU：主图、原产国、价格、库存（无 SKU 时）、`has_sku` |
| `cb_product_sku` | `CbProductSku` | SKU：规格、价格、库存 |
| `cb_cart_item` | `CbCartItem` | 购物车行 |
| `cb_address` | `CbAddress` | 收货地址 |
| `cb_order` | `CbOrder` | 订单头；含 `activity_id`（秒杀单关联活动） |
| `cb_order_item` | `CbOrderItem` | 订单行快照 |
| `cb_payment` | `CbPayment` | 模拟支付单；渠道名可记 ALIPAY / WECHAT / STRIPE |
| `cb_seckill_activity` | `CbSeckillActivity` | 秒杀活动：价格、库存、时间窗、状态 |

订单状态字符串与 `OrderStatus` 一致：`UNPAID` / `PAID` / `SHIPPED` / `COMPLETED` / `CANCELLED`。

## SQL 脚本顺序

详见 [数据库初始化说明.md](../数据库初始化说明.md)。摘要：

| 文件 | 作用 |
|------|------|
| `crossborder_mall.sql` | 历史用户等底表 |
| `cb_mall_commerce.sql` | 分类 / 商品 / SKU 与基础种子 |
| `cb_mall_trade.sql` | 地址、购物车、订单、支付 |
| `cb_mall_seckill.sql` | 秒杀活动表与示例活动 |
| `cb_mall_demo_seed.sql` | **演示扩展**：更多商品 + 外链主图 + 秒杀补种 |
| `cb_mall_order_activity.sql` | 旧库补 `activity_id`（新库已有则跳过） |
| `cb_mall_drop_legacy.sql` | 删除课设遗留店铺 / 笔记等表 |

`docker-compose` 首次启动会按编排挂载执行相关脚本。

## Mapper

`mapper` 包内接口对应上表；订单等关键路径使用条件更新（CAS）保证并发下状态正确。

## 这一层不做什么

- 不解析 JWT  
- 不发 MQ  
- 不返回页面 HTML
