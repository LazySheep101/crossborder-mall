# 缓存与工具层

这一层提供可复用的 Redis 能力与小工具，被业务层调用。包：`com.crossborder.mall.utils`。键前缀集中在 `RedisConstants`。

## Redis 键约定

| 常量 / 键 | 含义 |
|-----------|------|
| `login:code:{phone}` | 登录验证码，短 TTL |
| `jwt:blacklist:{token}` | 登出拉黑，TTL = Token 剩余寿命 |
| `cache:product:{id}` | 商品详情缓存（逻辑过期） |
| `seckill:stock:{activityId}` | 秒杀剩余名额 |
| `seckill:order:{activityId}` | 已抢用户集合（一人一单） |
| `seckill:result:{activityId}:{userId}` | 秒杀结果：排队 / 成功 / 失败 |
| `seckill:msg:done:{requestId}` | 秒杀消息消费幂等标记 |

空值防穿透：短 TTL 的空串缓存（`CACHE_NULL_TTL`）。

## 工具类

| 类 | 作用 |
|----|------|
| `CacheClient` | 逻辑过期读写、空值缓存、互斥重建 |
| `SimpleRedisLock` / `ILock` | 分布式锁（含持有者校验，避免误删别人的锁） |
| `RedisRateLimiter` | 秒杀等场景简易限流 |
| `RedisIdWorker` | 基于 Redis 的业务单号片段 |
| `UserHolder` | 当前登录用户 ThreadLocal |
| `RegexUtils` | 手机号等校验 |

商品详情：`ProductCatalogServiceImpl` 用 `CacheClient.setWithLogicalExpire`；后台改商品 / 库存变更时 `evictProduct`。

## 这一层不做什么

- 不单独对外提供 HTTP  
- 不包含订单状态机业务规则  
- 不替代数据库事务
