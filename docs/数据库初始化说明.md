# 数据库初始化说明

## 当前库

| 项 | 值 |
|----|----|
| 库名 | `crossborder_mall` |
| 主机 | `127.0.0.1:3306`（可用环境变量覆盖） |
| 账号 | 见 `application.yml` / `DB_USERNAME` / `DB_PASSWORD` |
| 用户表 | `tb_user`（手机验证码登录，保留） |
| 商城表 | `cb_category` / `cb_product` / `cb_product_sku` / `cb_address` / `cb_cart_item` / `cb_order` / `cb_order_item` / `cb_payment` / `cb_seckill_activity` |

应用：`application.yml` 默认 `DB_NAME=crossborder_mall`。

表字段与订单状态说明见 [层/数据层.md](层/数据层.md)。

## SQL 文件

按顺序理解即可（Compose 已挂载常用脚本）：

| 文件 | 作用 |
|------|------|
| `crossborder_mall.sql` | 历史用户等底表。导入后可执行 `cb_mall_drop_legacy.sql` 删课设旁路表 |
| `cb_mall_commerce.sql` | 商品域 + 基础种子商品 |
| `cb_mall_trade.sql` | 交易域（含 `cb_order.activity_id`） |
| `cb_mall_seckill.sql` | 秒杀活动表 + 示例活动 |
| `cb_mall_demo_seed.sql` | **演示扩展**：更多带图商品、补种秒杀（推荐本地演示执行） |
| `cb_mall_order_activity.sql` | 旧库补 `activity_id`；新库已有该列时不要再执行 |
| `cb_mall_drop_legacy.sql` | 删除不再使用的课设表 |

```powershell
.\docs\scripts\init-db.ps1 -Password <你的密码>
```

演示种子（PowerShell 示例）：

```powershell
Get-Content -LiteralPath .\crossborder-mall-backend\src\main\resources\db\cb_mall_demo_seed.sql -Encoding UTF8 -Raw |
  mysql -h127.0.0.1 -P3306 -uroot -p<密码> --default-character-set=utf8mb4 crossborder_mall
```

已有库只补秒杀订单列时，单独执行 `cb_mall_order_activity.sql`。列已存在会报错，忽略即可。
