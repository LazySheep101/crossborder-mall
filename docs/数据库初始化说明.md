# 数据库初始化说明

## 当前库

| 项 | 值 |
|----|----|
| 库名 | `crossborder_mall` |
| 主机 | `127.0.0.1:3306` |
| 账号 | `root` / `123`（本机可用环境变量覆盖） |
| 用户表 | `tb_user`（手机验证码登录，保留） |
| 商城表 | `cb_category` / `cb_product` / `cb_product_sku` / `cb_address` / `cb_cart_item` / `cb_order` / `cb_order_item` / `cb_payment` / `cb_seckill_activity` |

应用：`application.yml` 默认 `DB_NAME=crossborder_mall`；dev 密码默认 `123`。

## SQL 文件

- `crossborder_mall.sql`：历史用户数据。导入后执行 `cb_mall_drop_legacy.sql`，删掉店铺、笔记、关注、优惠券、签到表。
- `cb_mall_commerce.sql`：商品域
- `cb_mall_trade.sql`：交易域（含 `cb_order.activity_id`）
- `cb_mall_seckill.sql`：秒杀活动
- `cb_mall_order_activity.sql`：旧库补 `activity_id`。新库已含该列时不要再执行。
- `cb_mall_drop_legacy.sql`：删除不再使用的课设表

```powershell
.\docs\scripts\init-db.ps1 -Password 123
```

已有库只补秒杀订单列时，单独执行 `cb_mall_order_activity.sql`。列已存在会报错，忽略即可。
